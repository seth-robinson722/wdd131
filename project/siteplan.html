CryptoSafe Checklist Site Plan

WDD 131 - Project Folder

Site Name

Name: CryptoSafe Checklist

Description: I chose this name because it is direct and professional. It clearly communicates the site's utility: a security-first resource for users to verify their crypto hygiene.

Site Purpose

The purpose of CryptoSafe is to provide a simplified, interactive security audit for individual crypto investors. It offers a 3-page experience: a security education home page, an interactive checklist form, and a "Best Practices" resource hub.

Target Audience Scenarios

  • "I just bought my first Bitcoin on an exchange; what steps should I take to move it to a private wallet safely?"
  • "How can I verify if a new DeFi website I'm connecting my wallet to is a known scam or safe to use?"
